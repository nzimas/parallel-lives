# ParallelLives 2026.8.11

ParallelLives now uses calendar versioning. This stable release supersedes the
earlier `0.1.x` labels, which understated the maturity of the instrument.

## Instrument

- Eight parallel left-to-right synthesis and processing tracks
- Twenty generator archetypes, including Karplus–Strong and physical models
- Fifteen animated processor families
- Immediate excitation for sparse physical sources, followed by irregular
  stochastic retriggering
- Harmonic relationships established by the first locked generator
- Generator locks and exact chain-prefix locks
- Click-safe chain construction, trimming, expansion, and scene recall

## Performance and control

- Complete standalone macOS trackpad surface
- Novation Launchpad Mini Mk3 Programmer-mode integration
- Per-track volume, pan, rhythmic gate, and four shared-effect sends
- Track scenes, global scenes, and persistent projects
- Parameterized reverb, delay, saturation/overdrive, and decimation returns
- Bundled Csound 6.18.1 runtime and dependencies

The release supports Apple Silicon Macs running macOS 14 or newer. It is ad-hoc
signed pending a Developer ID certificate.
